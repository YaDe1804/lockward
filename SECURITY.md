# Security policy

## Supported versions

Lockward is pre-1.0. Security fixes go to the latest release only.

| Version | Supported |
| --- | --- |
| 0.1.1 | yes |
| 0.1.0 | no |

## Reporting a vulnerability

Report a vulnerability in private. Use
[GitHub Private Vulnerability Reporting](https://github.com/YaDe1804/lockward/security/advisories/new)
or email Deniz Yayvan at `deniz.yayvan@yadelabs.de`. Do not open a public
issue for an undisclosed vulnerability.

Include what you can of the following:

- a description of the issue
- the commit or version you ran
- a minimal lockfile or input that reproduces it, with secrets removed

Inert proof-of-concept files are welcome. Do not send live malware
samples. Lockward's fixtures are synthetic on purpose.

There is no bug-bounty program.
