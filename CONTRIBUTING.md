# Contributing to Lockward

Thanks for your interest. Two things first:

1. **Quality:** see `.cursorrules` — static analysis (no execution of
   package code), path containment, advisory coverage, input limits, escaping,
   `Result`/`#![forbid(unsafe_code)]`, tests required, current crates.
2. **License of contributions (CLA):** because Lockward is dual-licensed, you
   must agree to the Contributor License Agreement described in `CLA.md`
   before a contribution is accepted. That keeps the commercial
   second license possible.
