# Contributing to Lockward

Danke für dein Interesse! Zwei Dinge vorab:

1. **Qualität:** siehe `.cursorrules` — statische Analyse (kein Ausführen von
   Paketcode), Pfad-Containment, Advisory-Abdeckung, Input-Limits, Escaping,
   `Result`/`#![forbid(unsafe_code)]`, Tests Pflicht, aktuelle Crates.
2. **Lizenz der Beiträge (CLA):** Da Lockward dual-lizenziert ist, musst du
   dem in `CLA.md` beschriebenen Contributor License Agreement zustimmen,
   bevor dein Beitrag aufgenommen wird. Damit bleibt die kommerzielle
   Zweitlizenz möglich.
